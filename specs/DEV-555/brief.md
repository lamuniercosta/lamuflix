## Frozen scope

Deliver a movies-only, keyless BSPlayer subtitle provider behind the DEV-551 seam. Include typed acquisition settings, provider-local validation and failure, the recorded SOAP contract and known-file hash proofs, and subtitle setup documentation. Use the existing provider-neutral API and preserve existing-track serving, language discovery, and the existing sidecar policy. TV support is out of scope. HTTPS is in scope only if BSPlayer offers it. Apart from the stated work, anything else is a follow-up issue, not a finding in this round.

## Approach and file boundaries

- Use `ISubtitleProvider` and the DEV-551 provider contract. Bind `Subtitles:BsPlayer` within the existing subtitle options records. Configure `Enabled`, the server list, the timeout and the BSPlayer-only `AllowPlainHttp: true` opt-in. Keep the repository default off and enable it in home settings. Keep OpenSubtitles HTTPS-only. Missing or invalid provider settings cause zero outbound calls for that provider and leave the host running. Preserve the DEV-551 request-time 409 when no enabled provider is usable and the read-only download policy precedence. Numeric bounds come from configuration. [Q1](CONCLUSIONS.md#q1-subtitle-acquisition-configuration)
- Constrain keyless SOAP and provider-returned downloads to explicitly configured server or download hosts with no wildcards. Disable redirects. Bound XML and download size, reject unsafe XML and disallowed destinations, and apply existing SRT validation before saving. Scrub anonymous session tokens from logs, telemetry and fixtures. If recorded evidence requires a different destination or redirect, seek an explicit ruling before relying on it. [Q2](CONCLUSIONS.md#q2-plain-http-and-recorded-protocol-evidence)
- Search by file hash and size, including IMDb ID when the movie has one. Use one configured provider deadline across probing, session open, search, any required delay and close, with injected `TimeProvider` and cancellation. Try servers in configured order with bounded attempts. Use the first successful session and close it best-effort while time remains. Add the 8-second wait only if required by recorded protocol evidence and charge it to the same deadline. DEV-552 owns the picker behavior that lets other providers show first if the wait is required. If no server answers, set BSPlayer to `failed` with “BSPlayer is not answering” while other providers return their results. [Q3](CONCLUSIONS.md#q3-provider-deadline-and-server-order)
- Work in the Infrastructure adapter and registration, Core subtitle options and validation, integration contract/fake and supporting tests, and subtitle setup docs and `SubtitleSetupDocumentationTests`. Include only the necessary appsettings and registration changes. Edit `MovieHash.cs` only if recorded evidence proves the hash differs, and preserve the OpenSubtitles hash behavior. Add config-state-only health wiring and bounded telemetry without a live probe. Use existing packages and projects. Keep the existing ports, layers, schema, public routes, DTOs and status codes. Local playback, process launch and credential handling remain outside the adapter. Obtain a separate Patron ruling for any additional file or dependency.
