# DEV-345 Assumptions

- `[assumed]` `FakeEmbeddingGenerator` derives each 384-element `float` vector deterministically from the UTF-8 input string via SHA-256 counter blocks and L2-normalizes the resulting vector to unit length (`1.0f`) so downstream cosine-distance tests have well-defined unit vectors (`specs/PRODUCT.md:28-29`, `DEV-345` Scope #2 & AC #1-#2).
- `[assumed]` `FakeEmbeddingGenerator` hashes exact UTF-8 input bytes with no case or whitespace normalization (`specs/PRODUCT.md:28-29`, `CONCLUSIONS.md` Q2).
- `[assumed]` `FakeEmbeddingGenerator` rejects `null` batch / `null` input elements and any non-null `options.Dimensions != 384`, while accepting empty batches and `""` (empty string) (`specs/PRODUCT.md:28-29`, `CONCLUSIONS.md` Q2).
- `[assumed]` SHA-256 expansion appends 4 big-endian counter bytes (`0u..47u`) to the UTF-8 input bytes, maps each of the 8 big-endian `uint` words per digest via `(word / 2147483648.0) - 1.0`, normalizes in `double` to unit L2 norm (`Math.Abs(norm - 1.0) <= 1e-6`, fallback `[1f, 0f, ...]`), and casts to `float` (`CONCLUSIONS.md` Drafting gaps #1-#3).
- `[assumed]` `EmbeddingDimensions` exposes `public const int Value = 384` and `public static void Validate(IEmbeddingGenerator<string, Embedding<float>> generator)`; `FakeEmbeddingGenerator` uses `new EmbeddingGeneratorMetadata(defaultModelDimensions: reportedDimensions)` with other metadata properties `null`, throws `ArgumentNullException` (null batch/element/serviceType) and `ArgumentOutOfRangeException` (`options.Dimensions != 384`), and checks cancellation at entry, per item, and before return (`CONCLUSIONS.md` Drafting gaps #4-#8).
