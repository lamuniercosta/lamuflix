- **Q2 (Denominator is the sum of all six configured criterion weights, 15 at defaults)**: Confirmed per ticket text.
  - `Score = (sum of weight x value over the six criteria) / (sum of all six weights)`; a criterion with missing data has value 0 and stays in the denominator, and the default denominator is 15 (`3+3+3+2+2+2`) (DEV-518 Wanted item 2).
  - Each criterion's contribution is `weight * value / denominator` (sum of all six configured weights, 15 by default) so the six contributions always sum to `Score` (DEV-518 Wanted item 5; Done when item 13).

- **Q3 (Graded display thresholds for Themes, Plot, and Genre require `value > 0` and `value >= threshold`, separate from score contribution)**: Confirmed per ticket text.
  - Show a reason only for a criterion that matched (`value > 0`) and whose value is at or above its configured display threshold (`value >= threshold`, defaults: Themes `0.3`, Plot `0.5`, Genre `0.5`), while Collection, Director, and Cast show a reason whenever `value > 0`; never show a reason for a criterion that did not match (`value == 0`, even if a display threshold is configured to `0`) (DEV-518 Wanted item 6; Open points: "Display threshold values").
  - A graded criterion with `0 < value < threshold` still contributes `weight * value / denominator` to `Score` and appears in evidence while emitting no reason string; pin both boundary equality (`value == threshold`) and positive below-threshold contribution in unit tests (DEV-518 Wanted items 5 and 6; Done when item 10).

- **Q4 (Themes zero-norm keyword vector when all counted keywords occur in every movie (`n_k == N`, `w_k = ln(N / n_k) == 0`))**: Confirmed (treat zero vector norm as raw cosine `0`, Themes value `0`, no reason).
  - Under `w_k = ln(N / n_k)`, any keyword appearing in all `N` library movies has `w_k = 0`; if either movie's weighted keyword vector has a zero norm (`sum(w_k^2) == 0`), the cosine denominator is zero and must evaluate to raw cosine `0` just like an empty counted-keyword vector, keeping `Score` finite (`0`, never `NaN`) (DEV-518 Wanted item 3; sound engineering practice).
  - Because a zero-weight keyword contributes `0` to the Themes value, `value == 0` emits no Themes reason (DEV-518 Wanted item 6; Q3 ruling).
