## Q3/12 — numerical semantics and vocabulary

**Keel question and recommendation:** Genre weight is a library rarity multiplier; GenreWeights is the immutable genre-ID weight table; Genre similarity is weighted Jaccard over genre-ID sets. Similarity is weighted intersection divided by weighted union: empty union/disjoint sets return 0; identical nonempty sets return 1; result finite, symmetric, bounded [0,1]. Do not apply RecommendationOptions.Weights.Genres. Clarify Q2: total zero preserves persisted zero-count genre rows; empty map only when no genre rows exist.
