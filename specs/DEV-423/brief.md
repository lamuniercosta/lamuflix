## Exact fallback algorithm (Q3)

| Observed result | Action |
| --- | --- |
| Found | Return that result immediately; never merge fields or call later providers. |
| NotFound | Continue to the next configured provider. |
| Failed(RateLimited) or Failed(ProviderUnavailable) | Remember the first eligible failure in provider order and continue. |
| Failed(InvalidResponse), Failed(Unknown), or any other Failed including DuplicateImdbId | Return that failure immediately without calling later providers. |
| Providers exhausted | Return the first remembered eligible failure if present; otherwise NotFound. |

Thus OMDb unavailable plus TMDb miss remains retryable; both eligible failures preserve OMDb precedence; a later terminal failure overrides any remembered eligible failure. A one-provider disabled chain returns the same OMDb result as before. Forward the original lookup and token unchanged, including ManualImdbId. Caller cancellation and unexpected exceptions propagate; the chain catches/reclassifies neither and never falls back on thrown exceptions. Adapter-specific manual-id/search behavior remains DEV-331/OMDb responsibility.
