# DEV-539 implementation brief

Patron closed the grill after eight questions on branch `feature/539-spec`. The [ticket](ticket-text.txt) and [full cited grill exchanges](CONCLUSIONS.md) govern this brief. Current-state facts come from `recon-DEV-539`. The Conductor claimed ADR 0048 after the ADR number check, and Patron accepted it in Q1. No structural owner question was raised.

## Frozen scope

Add Crowd, a binary item-to-item similarity criterion sourced from the first page of TMDb movie recommendations, for For you and Related. Persist TMDb identities and recommendation lists, seed existing IMDb-identified movies by a manual backfill, resolve links at the existing library feature load, and use DEV-545 evidence to determine the strong-match threshold and default activation.

A **Crowd link** exists between distinct library movies when either movie's stored recommendations include the other's TMDb ID. A **recommended TMDb ID** can refer to a movie outside the library and is retained for future resolution. Only library movies enter the candidate set. No local peer-history collaborative filtering, TMDb similar lists, TMDb user ratings, second external source, or changes to keyword, cast or trailer enrichment. No public HTTP route, DTO, status code or frontend changes. The existing LocalPlay boundary stays in place. Anything else is a follow-up issue, not a finding in this round.

## Test and acceptance strategy

- Integration tests through the real resilient typed HttpClient and WireMock prove the exact `movie/{id}/recommendations` path, first-page-only behavior even when more pages exist, and persisted IDs. Verify successful empty replacement and the failure rules for unchanged and changed source IDs.
- Exercise the migration against existing movie data. Use real database integration coverage for persisted mappings, link resolution and atomic retries. Cover backfill configuration refusal, missing IMDb IDs, stored IDs, unmatched finds, matched writes, failed recommendation fetches, repeat invocation, and truthful counts.
- Prove late library additions activate stored links without another enrichment of the source. Pin symmetry, binary contribution, no self-links, and library-only returned movies.
- Pin the criteria order, default weight, contribution, denominator and reason text. Use DEV-545 baselines to prove exact For you and Related score parity separately for disabled TMDb and enabled TMDb with a blank key. Exercise Crowd active and explicitly inactive with TMDb configured.
- Before delivery, demonstrate migration application to the existing home library and publish actual backfill and DEV-545 results. The historical library size is context. Use measured counts in the PR.
