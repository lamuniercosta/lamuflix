## Canonical terms for drafting

A snapshot records API-returned lists and their order. A compare ranking scores one selected movie against every other enriched library movie, independently of pool truncation, profile blend and MMR. A hidden seed retains its identity as a candidate while its watched/review/profile signals are cleared in a fresh in-memory evaluation copy. A strong match has a supported Collection, Director or Themes criterion value of 1; before DEV-518 only Collection and Director are available. A judged pair is directed from movieId to otherId, with an owner-provided good/bad verdict. These definitions describe the approved harness contract, not new production behavior.

### Q5 — Compare and breakdown

Derive weighted criterion name/value/weight/contribution from existing collected terms and denominator, with inactive/zero-denominator weighted contribution zero. PC1 adds only the existing identical-profile zero-weight identity-fallback diagnostic (value 1, weight 0, contribution 1, never strong); omit uncollected criteria and preserve scoring behavior. Populated pair-score diagnostics sum to score; production blend instances have empty diagnostics. PC3 requires an initialized immutable non-positional property preserving two-argument construction/deconstruction. Preserve all existing expected scorer scores and reason contents/order. No public DTO/OpenAPI change. Compare excludes self, orders score descending then ID ascending, computes raw cosine and plot rank across all other enriched movies with cosine-descending/ID-ascending ties, and marks pool membership as plot rank <= CandidatePoolSize OR same collection. Pair mode prints only that pair and actual matched director/cast/keyword/genre/collection names from runner-local intersections of loaded feature IDs/names, never reason-text parsing. PC2 defines enriched as EnrichmentStatus.Enriched; retain all enriched rows, use persisted usable vectors with production-equivalent cosine, and report null cosine/rank for unusable pairs without dropping rows. Plot order includes only usable pairs. The ticket pool formula remains (non-null plotRank <= CandidatePoolSize) OR same collection with the production vector-gate limitation disclosed. Output uses Q6 common rows plus diagnostics.

### Q6 — Snapshot and diff

Preserve exact API order and every reason kind/text. Capture includes mode, seed IDs, take values, rows, and empty-list status; no timestamp, hostname or elapsed time. Always print moved up, moved down, entered, left, reasons changed (including kind/text sequence changes), even if groups are empty. Compare adds breakdown/plot/pool fields. ### Q7 — Quality

Default bars: 0.15, 0.20, 0.225, 0.25, 0.30, 0.35, 0.40. Score all other enriched movies for every enriched selection. At each bar print score-only and score-OR-strong lines. Each line's 0/1-3/4-10/>10 buckets partition the entire enriched-selected population. Median first/tenth qualifying result scores exclude missing ordinals, show contributing counts and return null if none. Do not synthesize Themes before it exists.

Adjacent sorted unique bars form [lower,upper) bands. Choose up to 12 directed non-self pairs per band by SHA-256 over UTF-8 invariant decimal selectedId:otherId with no spaces/newline, ordered by full digest bytes lexicographically then numeric IDs (PC3); disclose undersupply. Add up to 12 under the configurable strong-only bar (default 0.225) that qualify through a strong criterion alone. Repeated runs choose identical pairs.

Owner-authored JSON judgments live under ignored artifacts/recommendations/: movieId, otherId, verdict good/bad, optional note. Reverse direction is a separate judgment. Reject malformed/duplicate directed entries. Visibly skip unknown or unenriched IDs, excluding them from denominators. Whole-library Q5 ranks precede bar filtering. For good pairs report rank1/top3/each-bar/strong shares; for bad pairs top3/each-bar/strong shares. Print each valid rank/score and each skipped entry; zero valid denominators give null. Keep the ticket's known-miss example in the owner-corrected good list unless the owner changes that verdict.
