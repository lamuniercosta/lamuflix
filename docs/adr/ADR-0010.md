# ADR-0010. TimeProvider, BannedSymbols, xUnit v3, and Testcontainers

- Status: Accepted
- Date: 2026-09-24
- Ticket: DEV-292 (parent DEV-281)

## Context

Timestamps must not come from the ambient clock. The plan's guarantees — atomic claim, NULLS LAST, and trace propagation — hold only against the real engine, so infrastructure tests cannot mock that engine away.

## Decision

- Timestamps come from an injected `TimeProvider`.
- `BannedSymbols.txt` bans `DateTime.Now`, `DateTime.UtcNow`, `DateTime.Today`, `DateTimeOffset.Now`, and `DateTimeOffset.UtcNow`.
- xUnit v3 is the only test framework. MSTest and NUnit are forbidden.
- Infrastructure is not mocked. Persistence and messaging tests use Testcontainers for Postgres and RabbitMQ. EF Core InMemory is forbidden.

## Consequences

- A `DateTime.Now`-family call fails the build.
- Integration tests for persistence and messaging run on Testcontainers.
