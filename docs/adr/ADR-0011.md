# ADR-0011. Content-based hybrid recommendations constrained to library

- Status: Accepted
- Date: 2026-10-16
- Ticket: DEV-344

## Context

LamuFlix is a single-user local film library. There is no cross-user signal: no ratings corpus, no peer histories, no shared behaviour to factorise. Recommendations must therefore derive from the content of the library itself and from the local user's own history within it.

## Decision

- Recommendations use a content-based hybrid over collaborative filtering. Candidate similarity combines local content signals (genre, people, year, and other library metadata) with the local user's own history. Collaborative filtering is rejected: there are no other users to collaborate with.
- Only movies physically on disk are ever recommended. The candidate set is the library itself; absent, remote, or unimported titles are never candidates.
- Every recommendation carries explainable reasons. A recommendation without reasons is not a valid recommendation.

## Consequences

- No external user data leaves the machine. The feature is fully private and works offline.
- DEV-340 implements this decision and must not merge before this ADR is accepted.
